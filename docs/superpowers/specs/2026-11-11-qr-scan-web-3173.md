# QR attendance scanning on the website (#3173)

Date: 2026-11-11. Owner decision (card, 09:12Z): the scanner works on phones and on computers with a camera, scans made offline are kept in the browser, and only coaches scan. Criteria 1325, 1326, 1329 were adapted to the web and criterion 3669 was added (owner approved them 09:16Z).

## Design

- Same entry point as the native app: `/coach/attendance` → session → "Scanează prezența" → "Scanează cod QR".
- Native keeps `@capacitor/barcode-scanner` (`native-scanner.ts`). On the web, `AttendanceScanner` opens `WebScannerSheet`: a bottom `Sheet` with the session label, the camera preview, "Încadrează codul QR al copilului" and an "Anulează" button. Escape, the close button and "Anulează" close it and stop the camera.
- Decoding uses the core `Html5Qrcode` class from `html5-qrcode` 2.3.8, pinned as a direct dependency and loaded lazily on the first scan. The plugin's own web modal is not used because it does not follow the design system.
- A decoded value goes through `tokenDinCod`; a valid token enters the same `AttendanceQueue` and `record-attendance` path as native. Foreign codes show the existing toast and queue nothing.
- `AttendanceProvider` now creates the queue for every COACH session, web included. Capacitor `Preferences` stores it in `localStorage` on the web, and `App.appStateChange` maps to `visibilitychange`, so retries work the same way.
- Camera problems (permission denied, no camera, unsupported browser, camera busy, unknown) are shown with `StatusView` inside the sheet; the manual roster stays available.

## Tradeoffs

- The camera start is deferred by one task so React StrictMode's mount/unmount/mount does not start two readers on the same element; each mount gets its own host element. Without this, one camera track stayed live after closing in development.
- The preview keeps the video's natural aspect ratio. Forcing a square video with `object-cover` broke html5-qrcode's canvas mapping and nothing decoded.
- No server, migration or edge function change.
