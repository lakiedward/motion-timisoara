# Live coach location after manual attendance

A parent can discover a course's active location share after an authorized organizer marks their child present, including by manual attendance. The rule applies to the exact occurrence and requires an active course enrollment. The coach starts sharing explicitly and the parent still opts in before receiving a point.

The discovery list, Realtime audience and location transaction use the same attendance rule. Correcting the mark to absent, clearing it or losing the active enrollment removes access. Camp arrival rules and sharing times stay as specified for feature #320.
